# دليل — إدارة العمل AH13

تطبيق عربي لإدارة الموظفين والجنسية والوظيفة والمواقع والملاحظات، صور الموظفين والهوية والإقامة، تنبيهات انتهاء الوثائق، الحضور والغياب والإضافي، المرتبات والسلف، المهام والتقارير وصلاحيات الفريق.

مطوّر الموقع: AH13
https://ahmedhafezfrontend-ah13.netlify.app

## تشغيل قاعدة البيانات

- إذا شغّلت ملف afaq-setup.sql السابق بنجاح، لا تشغّله مرة أخرى. «دليل» يستخدم الجداول نفسها التي تبدأ بـ afaq؛ تغيير الاسم لا يمس بياناتك.
- للمشروع الجديد: افتح Supabase ثم SQL Editor، والصق كود ملف daleel-setup.sql وشغّله مرة واحدة.
- التطبيق مرتبط بالفعل بعنوان مشروعك والمفتاح العام الذي أرسلته. لا تضف مفتاح service_role إلى أي ملف موقع.

## رفع الموقع على GitHub Pages

1. فك ضغط الحزمة وارفع الملفات التالية إلى جذر مستودع الموقع: index.html، manifest.webmanifest، sw.js، icon.svg، logo.png، icon-192.png، icon-512.png، icon-maskable.png.
2. افتح Settings ثم Pages، واختر Deploy from a branch وحدّد فرع main ومجلد root، ثم Save.
3. افتح رابط الموقع بعد انتهاء النشر.
4. في Supabase افتح Authentication ثم URL Configuration. ضع رابط موقع دليل في Site URL، وأضفه إلى Redirect URLs. هذه الخطوة لازمة لتأكيد البريد واستعادة كلمة المرور.
5. تأكّد من تفعيل تسجيل الحسابات باستخدام البريد الإلكتروني في Supabase.
6. أنشئ حسابك من دليل، وافتح رسالة تأكيد البريد، ثم سجّل الدخول وأنشئ مساحة العمل باسم المنشأة.

يعمل الموقع من جذر الموقع أو من مجلد مستودع GitHub Pages؛ روابط الأيقونة والتثبيت نسبية. التثبيت يحتاج HTTPS. لا تحتاج رفع ملف SQL إلى موقعك.

## استخدام دليل

- أضف الموظف أولًا. الجنسية نص يكتبه المستخدم وليست قائمة إجبارية.
- افتح «الملف والوثائق» لإضافة صورة أو هوية أو إقامة، أو استخدم صفحة الوثائق.
- الملفات المقبولة: JPEG وPNG وWEBP وPDF، بحد أقصى 10 ميجابايت للملف.
- المرفقات تحفظ في مخزن afaq-private داخل Supabase. لا ترفع صور الموظفين ووثائقهم إلى GitHub.
- من الحضور سجّل الحالة والتوقيت والموقع وعمل اليوم والساعات الإضافية وأجر الساعة.
- في كشف الراتب استخدم «جلب الأساسي والإضافي» لاستيراد القيم المسجّلة للشهر. يمكنك مراجعتها وتعديلها قبل الحفظ.
- خصم السلف من الراتب لا يحدّث سداد السلفة تلقائيًا. سجّل السداد في صفحة السلف لتحديث المتبقي.
- التنبيهات تظهر داخل التطبيق عند فتحه لوثيقة منتهية أو تنتهي خلال 30 يومًا؛ لا توجد إشعارات دفع أو رسائل تلقائية في هذا الإصدار.
- بيانات التقرير تصدر إلى CSV، ويمكن طباعة تقرير الشهر.
- تنزيل JSON يحفظ السجلات فقط، وليس ملفات المرفقات، ولا يتضمن استيرادًا تلقائيًا لهذه النسخة.

## الفريق والصلاحيات

1. ينشئ كل عضو حسابه الخاص ويؤكد البريد.
2. ينسخ العضو معرّف حسابه من صفحة «الفريق والإعدادات» ويرسله إلى المالك.
3. يضيف المالك المعرّف ويختار «مدير» أو «قراءة فقط».
4. يسجّل العضو الدخول أو يحدّث الصفحة ليرى مساحة العمل.

المالك يدير العضوية، والمدير يعدّل السجلات، والقارئ يقرأ السجلات والمرفقات. كل أعضاء مساحة العمل يمكنهم قراءة بياناتها الحساسة وفق هذا النموذج؛ لا تمنح الصلاحية إلا للموظف المناسب. لا توجد صلاحيات منفصلة لكل موظف في هذا الإصدار.

## تثبيت التطبيق

- Android: افتح الرابط في Chrome ← القائمة ← تثبيت التطبيق / إضافة إلى الشاشة الرئيسية.
- iPhone: افتح الرابط في Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.
- Windows: افتح الرابط في Edge أو Chrome ← رمز التثبيت في شريط العنوان أو قائمة التطبيقات.

اسم التطبيق المثبّت «دليل» ويستخدم الأيقونة المرفقة. واجهة التطبيق يمكن أن تُفتح دون اتصال بعد زيارة الموقع، لكن تحميل السجلات وحفظها يحتاج الإنترنت. لا توجد واجهة تجريبية أو بيانات مثال ضمن المنتج.

## إذا ظهرت رسالة خطأ

- الجداول غير جاهزة: تأكّد من نجاح تنفيذ SQL على مشروع Supabase الصحيح.
- البريد غير مؤكّد: أكّد رسالة التسجيل قبل الدخول.
- تعذّر الاتصال: تحقّق من الإنترنت ومن أن مشروع Supabase يعمل.
- لا توجد صلاحية: راجع عضوية الحساب ودوره في مساحة العمل.

تم فحص منطق الواجهة باستخدام استجابات اختبار معزولة. لم يُتحقق من تسجيل الدخول والحفظ على مشروع Supabase الفعلي من بيئة التنفيذ.


## النسخة الجديدة

تتضمن الشعار الأفقي المعتمد والخلفية المتدرجة، وأيقونات التثبيت الجديدة، وواجهة بألوان الكحلي والذهبي. ارفع جميع ملفات الموقع واستبدل الملفات القديمة؛ ملف SQL لا يحتاج إعادة تشغيل إذا كانت الجداول السابقة موجودة.
